# PA11 / PA12 engineering selection worksheet

PA12 is a general-purpose starting point; PA11 is often shortlisted when ductility, impact or repeated movement matters. These are qualitative material-family tendencies, not a guaranteed ranking for two specific printed grades.

| Requirement to record | Engineer's input | Evidence to request |
|---|---|---|
| Function and failure consequence | Housing, clip, fixture or another function | Drawing and acceptance criteria |
| Load | Magnitude, direction, duration, impact | Grade data and a representative test |
| Movement | Displacement and target cycles | Test the actual flex zone and orientation |
| Environment | Temperature, moisture, chemicals, cleaning | Exact exposure and acceptance limits |
| Geometry | Walls, transitions, interfaces, trapped cavities | DFM review and depowdering access |
| Finish | Texture, smoothing, paint, color | Approved sample and dimensional checks |
| Material | Exact powder grade and permitted alternatives | Current TDS, specimen and test conditions |
| Production | Quantity, inspection, destination | Project-specific manufacturing review |

## Comparing candidates

1. Complete the same worksheet for both candidates.
2. Compare values using compatible test methods, orientation and conditioning.
3. Identify which requirement cannot be decided from a data sheet.
4. Print representative geometry, define pass/fail criteria and compare candidates under the same conditions.
5. Record the selected grade, process and finish for repeat orders.

Do not substitute PA12 for a drawing-specified PA11 without customer agreement. An alternative should be qualified against the required part behavior.

Sources checked 3 October 2026: [TPM3D PA11](https://www.sls-3d.com/materials/pa11) and [TPM3D PA12](https://www.sls-3d.com/materials/pa12). This worksheet introduces no numerical mechanical-property claims.
